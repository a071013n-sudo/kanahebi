# カナヘビ観察日記

写真を撮ると、見た目からわかる範囲の気になる点と世話のアドバイスを返してくれるPWA(Androidのホーム画面にインストールできるWebアプリ)です。

**大事な前提**
このアプリは獣医の診断の代わりにはなりません。写真だけでは内臓疾患や寄生虫などはわかりません。「気づきのきっかけ」として使い、心配な様子があれば爬虫類を診られる動物病院に相談してください。

---

## 構成

```
index.html      … 本体(撮影・結果表示・履歴)
manifest.json   … PWA設定
sw.js           … オフラインキャッシュ用Service Worker
icons/          … アプリアイコン
Code.gs         … Google Apps Script(Claude APIへのプロキシ)
```

`index.html` はGAS(Apps Script)を経由してGemini API(`gemini-3.6-flash`)に画像を送ります。APIキーはGAS側のスクリプトプロパティに保存されるので、フロントエンドのコードには一切含まれません。

---

## セットアップ手順

### 1. Gemini APIキーを取得
https://aistudio.google.com/apikey でAPIキーを発行します。無料枠がありますが、上限や料金体系は変わることがあるので、最新の内容をGoogle AI Studioの案内で確認してください。

### 2. GAS側(プロキシ)を用意
1. https://script.google.com で新規プロジェクトを作成
2. `Code.gs` の中身を貼り付け
3. 左メニュー「プロジェクトの設定」→「スクリプト プロパティ」で
   - キー: `GEMINI_API_KEY`
   - 値: 取得したAPIキー
   を追加
4. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」
   - 実行するユーザー: 自分
   - アクセスできるユーザー: 全員
5. 発行された `https://script.google.com/macros/s/.../exec` のURLを控える

### 3. PWA側を公開
GitHubリポジトリの `docs/` フォルダなどに `index.html` `manifest.json` `sw.js` `icons/` をまとめて置き、GitHub Pagesを有効化するのが簡単です(いつもの配布用リポジトリの延長で運用できます)。

### 4. Android側で使う
1. AndroidのChromeで公開したURLを開く
2. アプリ初回起動時、右上「⚙ 接続設定」に手順2で控えたGASのURLを貼り付けて保存
3. Chromeのメニュー「ホーム画面に追加」でアイコンがホームに追加され、アプリのように起動できます

## 注意点・既知の制約

- **GASのCORS**: Webアプリ(`/exec`)へのPOSTは、リクエストヘッダーを `text/plain` にすることでブラウザのpreflightを回避しています。まれに環境によって失敗する場合は、GAS側を一度ブラウザで直接開いて認証(このアプリにアクセスを許可)を済ませてから再度お試しください。
- **画像は外部(Google Gemini API)に送信されます**。ペットの写真という前提で問題なければそのままで大丈夫ですが、気になる場合はその旨を認識した上でご利用ください。
- Geminiは内容によっては安全フィルタで応答をブロックすることがあります。その場合は`Code.gs`が「Geminiから有効な応答が得られませんでした」というエラーを返すので、写真の構図(暗すぎる・不鮮明など)を変えて試してみてください。
- **履歴はブラウザのlocalStorageに保存**されます。端末やブラウザを変えると引き継がれません(必要ならGoogleスプレッドシートへのログ保存機能を追加することも可能です)。
- 診断ロジックのプロンプトは `Code.gs` の `buildSystemPrompt()` にあります。見てほしい項目(例: 産卵兆候、特定の疾患サインなど)を追加したい場合はここを編集してください。
- モデル名は `Code.gs` 冒頭の `MODEL` 変数(`gemini-3.6-flash`)にまとめてあります。Googleがモデルを更新・廃止した際はここを差し替えてください。
